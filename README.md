# TeamX VC Music Bot

A Telegram Voice Chat Music Bot built with Pyrogram & PyTgCalls.

## ⚙️ Features
- Play music in group voice chats using `/play <song>`
- Inline options: add to group, usage guide, clone link
- Welcome message for new users

## 🚀 Setup & Deploy

### 1. Use this template
Click **Use this template** → choose your repo name.

### 2. Add credentials
In your repo, create `.env` file:
```env
API_ID=<your_api_id>
API_HASH=<your_api_hash>
BOT_TOKEN=<your_bot_token>
